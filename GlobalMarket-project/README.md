## Descripcion del Proyecto
Este proyecto utiliza un dataset basado en Amazon Sales para crear una base de datos documental en MongoDB Atlas, aplicar validaciones, realizar consultas CRUD y agregaciones, y construir un dashboard analitico.

## Estructura del Repositorio
- **datasets/** - Muestra del dataset
- **modeling/** - Modelo documental 
- **validations/** - Validaciones 
- **queries/** -  Agregaciones
- **Explain Plan/** 
- **dashboard/** -  dashboard 
- **docs/** - Documentacion 

## Como usar este repositorio
Este repositorio contiene todo el desarrollo del proyecto para evaluacion:
1. Modelo documental
2. Validaciones de colecciones
3. Consultas 
4. Agregaciones
5. Dashboard analitico
